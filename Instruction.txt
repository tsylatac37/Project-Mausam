Git and GitHub CLI Setup Guide
1. Installation
Windows

    Git: Download from git-scm.com.

    GitHub CLI: Run in PowerShell: winget install --id GitHub.cli

MacOS

    Git & GH: Run in Terminal: brew install git gh

Linux (Debian/Ubuntu)

    Git: sudo apt update && sudo apt install git -y

    GitHub CLI: sudo apt update && sudo apt install gh -y

2. Authentication

Log in to your GitHub account via the terminal:
Bash

gh auth login

Select GitHub.com > HTTPS > Login with a web browser.
Project Workflow Commands
Initial Setup

Clone the repository to your local machine:
Bash

git clone https://github.com/tsylatac37/Weather-Telemetry-System.git
cd Weather-Telemetry-System

Daily Development Cycle
Step 1: Update your local code

Always run this before you start working to avoid conflicts.
Bash

git pull origin main

Step 2: Create a branch

Do not work directly on the main branch. Create a new branch for your specific task.
Bash

git checkout -b branch-name

Step 3: Save and Stage changes

After editing files, stage them for a commit.
Bash

git add .

Step 4: Commit changes

Provide a short, descriptive message of what you changed.
Bash

git commit -m "Description of changes"

Step 5: Push to GitHub

Upload your branch to the remote repository.
Bash

git push origin branch-name

Step 6: Create a Pull Request (PR)

Once pushed, use the GitHub CLI to notify the team for review.
Bash

gh pr create --title "Brief title" --body "Detailed description of work"

Useful Management Commands

    Check status: git status (See which files are modified)

    Switch branches: git checkout branch-name

    List branches: git branch

    Discard local changes: git restore <file-name>
